# Security Policy

> **In short:** report vulnerabilities privately, never in public issues or pull requests.

## Reporting

Use [private vulnerability reporting](https://github.com/steve-r-lewis/westray-papa-westray/security/advisories/new). Include the affected page, file or commit, the impact and how to reproduce it. Never include credentials, tokens or personal data.

## Scope

| In scope | Report to |
|---|---|
| This application: its screens, configuration, adapters and deployment | Here |
| A `nuxt4-layers` capability it uses | That capability's repository |

## Supported versions

The current `master` branch and the live site only.

## Secrets

No secret is ever committed. Deployment secrets live in the hosting provider's environment settings.
